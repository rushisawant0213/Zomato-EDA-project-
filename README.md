# 🍽️ Zomato Data Analysis Project

## 📌 Overview
This project analyzes Zomato restaurant data to uncover insights about restaurant ratings, cuisines, pricing, online delivery, and customer preferences.

## 🎯 Objectives
- Analyze restaurant ratings and reviews.
- Identify popular cuisines.
- Study the impact of online delivery and table booking.
- Explore price ranges across restaurants.
- Visualize trends using charts and graphs.

## 📊 Dataset
The dataset contains information about:
- Restaurant Name
- Location
- Cuisine
- Ratings
- Votes
- Average Cost for Two
- Online Delivery
- Table Booking

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Analysis Performed
- Data Cleaning
- Handling Missing Values
- Exploratory Data Analysis (EDA)
- Rating Distribution Analysis
- Cost Analysis
- Cuisine Popularity Analysis
- Data Visualization

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/zomato-project.git
   ```

2. Install required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn
   ```

3. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

4. Run the notebook.
